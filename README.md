# Shell Emulator

Эмулятор оболочки ОС для дисциплины "Конфигурационное управление".
Вариант 13.

## Описание

Консольный эмулятор UNIX-подобной оболочки с поддержкой:
- Интерактивного режима (REPL)
- Динамического приглашения к вводу на основе данных ОС
- Раскрытия переменных окружения ($VAR, ${VAR})
- Настраиваемости через аргументы командной строки
- Выполнения стартовых скриптов с имитацией диалога

Использует стандартную библиотеку shlex для парсинга команд.

## Настройки и параметры запуска

При запуске эмулятора можно передать следующие параметры:
- `--vfs, -v` — путь к физическому расположению VFS
- `--prompt, -p` — пользовательское приглашение к вводу
- `--script, -s` — путь к стартовому скрипту с командами

При запуске в консоль выводится отладочная информация `[DEBUG]` со всеми заданными параметрами.
