# Shell Emulator

Эмулятор оболочки ОС для дисциплины "Конфигурационное управление".
Вариант 13.

## Описание

Консольный эмулятор UNIX-подобной оболочки с поддержкой:
- Интерактивного режима (REPL)
- Динамического приглашения к вводу на основе данных ОС
- Раскрытия переменных окружения ($VAR, ${VAR})
- Настраиваемости через аргументы CLI
- Выполнения стартовых скриптов с имитацией диалога
- Виртуальной файловой системы (VFS) на основе директории
- Команд работы с файлами и историей

Использует стандартную библиотеку shlex для парсинга команд.

## Настройки и параметры запуска

При запуске эмулятора можно передать следующие параметры:
- `--vfs, -v` — путь к директории VFS
- `--prompt, -p` — пользовательское приглашение к вводу
- `--script, -s` — путь к стартовому скрипту с командами

При запуске выводится отладочная информация `[DEBUG]` со всеми
заданными параметрами.

## Команды эмулятора

### Основные команды
- `ls [path]` — список файлов в директории VFS
- `cd [path]` — смена текущей директории в VFS
- `vfs-info` — информация о VFS (имя и SHA-256 хеш)
- `exit` — завершение работы

### Команды работы с файлами
- `uniq [file]` — вывод уникальных строк файла (удаляет подряд
  идущие дубликаты)
- `tail [-N] [file]` — вывод последних N строк файла (по умолчанию 10)

### Служебные команды
- `history` — показать историю выполненных команд в сессии
