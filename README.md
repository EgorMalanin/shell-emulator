# Shell Emulator - Этап 1 (REPL)

Эмулятор оболочки ОС для дисциплины "Конфигурационное управление".
Вариант 13, Этап 1.

## Описание

Консольный эмулятор UNIX-подобной оболочки с базовым REPL интерфейсом.

## Функции

### Команды
- `ls [args]` — список файлов (заглушка)
- `cd [path]` — смена директории (заглушка)
- `exit` — завершение работы

### Особенности
- Динамическое приглашение к вводу: `username@hostname:~$`
- Раскрытие переменных окружения: `$VAR` и `${VAR}`
- Поддержка аргументов в кавычках
- Обработка ошибок неизвестных команд

## Запуск

```bat
run.bat
