# Shell Emulator

Эмулятор оболочки ОС для дисциплины "Конфигурационное управление".
Вариант 13.

## Описание

Консольный эмулятор UNIX-подобной оболочки с поддержкой:
- Интерактивного режима (REPL)
- Динамического приглашения к вводу
- Раскрытия переменных окружения ($VAR, ${VAR})
- Настраиваемости через аргументы CLI
- Выполнения стартовых скриптов
- Виртуальной файловой системы (VFS) на основе директории

## Параметры запуска

- `--vfs, -v` — путь к директории VFS
- `--prompt, -p` — пользовательское приглашение
- `--script, -s` — путь к стартовому скрипту

При запуске выводится отладочная информация `[DEBUG]`.

## Команды

- `vfs-ls [path]` — список файлов в VFS
- `vfs-cd [path]` — смена директории в VFS
- `vfs-info` — информация о VFS (имя и SHA-256)
- `exit` — завершение работы

## Запуск

```bat
.\run.bat
.\run.bat --vfs tests\vfs_nested
.\run.bat --vfs tests\vfs_nested --script tests\script_vfs_nested.txt
