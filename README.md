# Shell Emulator

Эмулятор оболочки ОС, имитирующий работу в командной строке
UNIX-подобных систем.
(Вариант №13).

## Общее описание

Консольный эмулятор оболочки с поддержкой:

- Интерактивного режима (REPL) с динамическим приглашением
- Раскрытия переменных окружения реальной ОС ($VAR, ${VAR})
- Парсинга аргументов в кавычках (через shlex)
- Настраиваемости через аргументы командной строки
- Выполнения стартовых скриптов с имитацией диалога
- Виртуальной файловой системы (VFS) на основе директории
- Команд работы с файлами и историей сессии

Все операции с VFS выполняются в памяти — реальная файловая
система не модифицируется.

## Параметры запуска

При запуске эмулятора можно передать следующие параметры:

- `--vfs, -v` — путь к директории VFS на диске
- `--prompt, -p` — пользовательское приглашение к вводу
- `--script, -s` — путь к стартовому скрипту с командами

При запуске выводится отладочная информация `[DEBUG]` со всеми
заданными параметрами в формате ключ-значение.

## Команды эмулятора

### Основные команды

- `ls [path]` — список файлов в директории VFS. Директории
  отображаются с суффиксом `/`, файлы — с размером в байтах.
- `cd [path]` — смена текущей директории в VFS. Поддерживает
  относительные и абсолютные пути, `..` и `/`.
- `rmdir [path]` — удаление пустой директории из VFS.
  Модификация только в памяти.
- `vfs-info` — информация о загруженной VFS: имя и SHA-256 хеш
  всех данных.
- `exit` — завершение работы эмулятора.

### Команды работы с файлами

- `uniq [file]` — вывод уникальных строк файла из VFS. Удаляет
  подряд идущие дубликаты, сохраняя порядок.
- `tail [-N] [file]` — вывод последних N строк файла из VFS.
  По умолчанию показывает 10 строк.

### Служебные команды

- `history` — показать нумерованный список всех команд,
  выполненных в текущей сессии.

## Сборка и запуск

### Запуск в интерактивном режиме

```bat
run.bat
run.bat --vfs tests\vfs_nested
.\run.bat --vfs tests\vfs_nested --script tests\script_vfs_nested.txt
.\run.bat --vfs tests\vfs_nested --script tests\test_stage4.txt
.\run.bat --vfs tests\vfs_nested --script tests\test_stage4.txt
